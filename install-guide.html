🎫 Zendesk Ticket Monitor

Chrome Extension — Installation Guide v3.5.4

📥 Step 1: Get the Extension

Option A — Download the ZIP (recommended for most users):

  1. Download barateza-ticket-notifier-3.5.4.zip from the releases page
  2. Extract the ZIP to a folder on your computer

Option B — Clone the repository (for developers):

git clone https://github.com/barateza/barateza-ticket-notifier-v3.git

📂 Step 2: Verify the Files

Your extension folder should contain these files:

  • manifest.json
  • background.js
  • offscreen.html
  • offscreen.js
  • popup.html
  • popup.css
  • popup.js
  • popup-endpoints.js
  • popup-settings.js
  • popup-snooze.js
  • popup-updates.js
  • popup-utils.js
  • icons/icon16.png
  • icons/icon48.png
  • icons/icon128.png
  • utils/ (directory with 11 modules)

⚙️ Step 3: Enable Developer Mode

  1. Open Google Chrome
  2. Navigate to chrome://extensions/
  3. Toggle "Developer mode" ON (top right corner)

📦 Step 4: Load the Extension

  1. Click "Load unpacked"
  2. Select the folder containing all the extension files
  3. Click "Select Folder"
✅ You should now see "Zendesk Ticket Monitor" in your extensions list with the icon!

🔑 Step 5: Log in to Zendesk

  1. Open a new tab and go to your Zendesk instance (e.g., https://your-domain.zendesk.com)
  2. Log in with your credentials
  3. The extension will automatically use your existing session cookies — no API tokens needed
Important: You must stay logged into Zendesk in at least one tab for the extension to work. If your session expires, just log in again.

🎯 Step 6: Configure Endpoints

  1. Click the extension icon in the Chrome toolbar
  2. Review the default endpoint — it monitors tickets assigned to you
  3. Add more endpoints as needed (e.g., specific groups, priorities)
  4. Adjust settings — check interval, sound, notifications, dark mode
  5. Test the setup by clicking "Refresh Now"

See the README for detailed endpoint URL examples and API reference.

🔊 Step 7 (Optional): Custom Notification Sound

  1. Open the extension popup and go to Settings
  2. Enable Custom Sound
  3. Paste a myinstants.com URL (e.g., a sound effect page)
  4. Click Fetch Sound — the extension automatically extracts the MP3 link
  5. Click Test to preview

🎉 Your extension is ready!

New tickets will trigger a sound and/or browser notification based on your settings.
